# The credential variables the sandbox check looks for in every process environment the session
# can read (probes.sh, parent-environ): the names only, never a value. One name per line, no CRLF;
# a line that is not a comment, empty or a name (^[A-Z][A-Z0-9_]*$) makes the whole scan a scan error.
# Source: Claude Code's docs, code.claude.com/docs/en/env-vars and
# code.claude.com/docs/en/authentication (read 2026-11-21), and the AWS credentials of Bedrock.
# ANTHROPIC_CUSTOM_HEADERS and OTEL_EXPORTER_OTLP_HEADERS can carry an Authorization header;
# GH_TOKEN and GITHUB_TOKEN are the GitHub CLI's.
# Not on the list: CLAUDE_CODE_MESSAGING_TOKEN. Claude Code exports it to hooks and Bash commands
# on purpose (the per-session inbox token, env-vars docs), so finding it is no sign that the login
# or API credential is readable. probes.sh counts it apart (messaging=N), and the judge notes it.
# No other name in those docs is passed to commands on purpose.
